# Rise of the bots — Year 9 Cybersecurity, Lesson 4

Interactive lesson (about 35–40 minutes in class) on **malware** and **bots**, adapted from the Teach Computing Curriculum (NCCE), Year 9 Cybersecurity, Lesson 4 "Rise of the bots", licensed under the [Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/).

**Part A · Malware** (about 28 min)

1. Ransom note — a harmless ransomware simulation: pay or don't pay?
2. What is malware? — malicious intent and the six categories → ✓ Check
3. Viruses — self-replicating code that a user has to run; common ways to catch one → ✓ Check
4. Worms — spreading through a network on their own and using up bandwidth; virus vs worm → ✓ Check
5. Ransomware and WannaCry (May 2017) → ✓ Check
6. Trojans — a useful-looking game that opens a back door → ✓ Check
7. Spyware and keyloggers → ✓ Check
8. Adware — pop-ups online and offline → ✓ Check
9. Which malware is it? — eight cases for the whole class

**Part B · Bots and botnets** (about 12 min)

10. Internet bots — search engine bots, chatbots, shopbots, bot traffic → ✓ Check
11. When bots go bad — fake followers, scanning for vulnerabilities, botnets and a DDoS attack → ✓ Check
12. Plenary — bots and the 2016 US election, with a think / write / pair / share timer → Activities (written answer + homework "malware quick read")
13. Exit quiz (10 multiple choice + 1 written answer, with "Copy my results") · Key terms

Each section shows its suggested minutes, and the **⏱ lesson clock** in the header counts up to 40 minutes (click to start or pause, double-click to reset).

**Progress:** saved in the student's browser (`localStorage`, key `rb-progress-v1`); **My progress** copies a report for the teacher and gives a progress code (`RB1Z.…`) to carry on with another device. Nothing is sent to a server.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F). Each scene has its own URL, e.g. `#worm` or `#check-botnet`.

Visual style: British School Alzira · Xàtiva · Gandia Group (BS Format). Plain HTML, CSS and JavaScript, no build step. All ransom notes, websites, messages and people are made up and harmless.
